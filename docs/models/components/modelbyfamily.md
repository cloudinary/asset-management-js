# ModelByFamily

Select a model by family and quality tier; a missing `tier` defaults to
`standard`.


## Example Usage

```typescript
import { ModelByFamily } from "@cloudinary/asset-management/models/components";

let value: ModelByFamily = {
  family: "flux",
  tier: "premium",
};
```
