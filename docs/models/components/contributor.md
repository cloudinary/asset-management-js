# Contributor

The identity behind the upload. Either the console user who performed it (custom_id and external_id)
or, when no console user was involved, the API key that signed the upload (access_key). The
get-resource and Search responses return one or the other, never both. When no contributor was
recorded (for example assets created before creator tracking) the Search API returns the field as
null and the get-resource response omits it.


## Example Usage

```typescript
import { Contributor } from "@cloudinary/asset-management/models/components";

let value: Contributor = {
  accessKey: "149945967172831",
  customId: "matthew@example.com",
  externalId: "0b8cd452de3ce172a6aec7af0a90db",
};
```
