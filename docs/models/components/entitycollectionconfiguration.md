# EntityCollectionConfiguration

Configuration for a `dynamic` collection. Required when creating a `dynamic` collection, and not allowed for a `manual` collection.


## Example Usage

```typescript
import { EntityCollectionConfiguration } from "@cloudinary/asset-management/models/components";

let value: EntityCollectionConfiguration = {
  expression: "tags = \"summer-campaign\" AND resource_type:image",
};
```
