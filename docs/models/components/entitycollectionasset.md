# EntityCollectionAsset

An asset in a collection. Every field is always present in a response: an unset value (`display_name`, or `width` / `height` for assets without dimensions) is returned as `null` rather than being omitted, the same as on the public page entity.


## Example Usage

```typescript
import { EntityCollectionAsset } from "@cloudinary/asset-management/models/components";

let value: EntityCollectionAsset = {
  assetId: "3515c6000a548515f1134043f9785c2f",
  publicId: "summer/beach-hero",
  displayName: "beach-hero",
  resourceType: "image",
  type: "upload",
  format: "jpg",
  bytes: 482113,
  width: 1920,
  height: 1080,
  secureUrl:
    "https://res.cloudinary.com/demo/image/upload/v1720000000/summer/beach-hero.jpg",
  createdAt: new Date("2026-03-14T10:15:00Z"),
};
```
