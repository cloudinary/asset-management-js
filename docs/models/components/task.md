# Task

An async generation task. Returned when a generation is accepted (202)
and from GET /tasks/{task_id} as it progresses. The `result` is filled
in once `status` is `completed`.


## Example Usage

```typescript
import { Task } from "@cloudinary/asset-management/models/components";

let value: Task = {
  taskId:
    "053f4bde4b933c8ecef23724ecde63b667c1ea21816d56c161c7ec1df6297da4b43109625650e9edf0f42152cc4cc32c8ad57824ac75ba8e05020f827c415559ac1248076a2d72c0a73af0479cca77eb",
  status: "completed",
  result: null,
  limits: {
    addonsQuota: [
      {
        type: "image_generation",
        usedByRequest: 1,
        remaining: 48,
        limit: 50,
      },
    ],
  },
};
```
