# ContextUpdateRequest

A contextual-metadata command plus the assets it applies to.

## Example Usage

```typescript
import { ContextUpdateRequest } from "@cloudinary/asset-management/models/components";

let value: ContextUpdateRequest = {
  publicIds: [
    "sample",
    "product_image",
    "banner_2023",
  ],
  command: "add",
  context: "alt=My image|caption=Nice photo",
};
```
