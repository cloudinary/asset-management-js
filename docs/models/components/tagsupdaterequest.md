# TagsUpdateRequest

A tag command plus the assets it applies to.

## Example Usage

```typescript
import { TagsUpdateRequest } from "@cloudinary/asset-management/models/components";

let value: TagsUpdateRequest = {
  publicIds: [
    "sample",
    "product_image",
    "banner_2023",
  ],
  command: "remove",
  tags: [
    "animal",
    "dog",
  ],
};
```
