# ResourceUpdateByBodyRequest

The asset identifiers plus the attributes to update. The identifying fields (public_id,
resource_type, kind) are required; the remaining update fields are optional. Additional
fields accepted by the asset update API are permitted.


## Example Usage

```typescript
import { ResourceUpdateByBodyRequest } from "@cloudinary/asset-management/models/components";

let value: ResourceUpdateByBodyRequest = {
  publicId: "sample",
  resourceType: "image",
  kind: "upload",
};
```
