# ErrorT

Details of an error, including a coarse category for retry logic, a stable error code, and a human-readable message.

## Example Usage

```typescript
import { ErrorT } from "@cloudinary/asset-management/models/components";

let value: ErrorT = {
  category: "user_error",
  code: "MG_00001",
  message: "missing parameters",
  details: {},
};
```
