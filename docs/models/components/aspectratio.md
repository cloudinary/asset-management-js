# AspectRatio

Output aspect ratio, width-to-height. Limited to the core ratios
every model supports natively.


## Example Usage

```typescript
import { AspectRatio } from "@cloudinary/asset-management/models/components";

let value: AspectRatio = "16:9";
```

## Values

```typescript
"1:1" | "16:9" | "9:16" | "4:3" | "3:4"
```
