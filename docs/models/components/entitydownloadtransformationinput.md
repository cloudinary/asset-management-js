# EntityDownloadTransformationInput

A named transformation to offer for download on a public page.

## Example Usage

```typescript
import { EntityDownloadTransformationInput } from "@cloudinary/asset-management/models/components";

let value: EntityDownloadTransformationInput = {
  name: "thumbnail_400",
  types: [
    "video",
  ],
};
```

                                                                                                         | Asset types the transformation is offered for. Restrict this to the types the transformation actually produces correct results for (for example, a duration/trim transformation only makes sense for video), to avoid download errors for the other type. This is a property of the transformation template itself, shared by every public page in the product environment, not just this one: it can only be set the first time any public page offers this name for download. Omit `types` on that first request to make it available for both `image` and `video`. If the name is already available for download (set by an earlier request on this or another public page), omit `types` to keep its existing setting, or send its exact current list; sending a different list fails with `download_transformation_types_conflict`.
