# MetadataUpdateRequest

Structured metadata values plus the assets they apply to.

## Example Usage

```typescript
import { MetadataUpdateRequest } from "@cloudinary/asset-management/models/components";

let value: MetadataUpdateRequest = {
  publicIds: [
    "sample",
    "product_image",
    "banner_2023",
  ],
  metadata: "in_stock_id=50|color_id=[\"green\",\"red\"]",
};
```
