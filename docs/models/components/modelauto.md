# ModelAuto

Let the service choose the model for this request. The response reports
the resolved model in `data.assets[].model`, as for the other forms; on
`image_to_image` it is always an edit model.


## Example Usage

```typescript
import { ModelAuto } from "@cloudinary/asset-management/models/components";

let value: ModelAuto = {
  mode: "auto",
  preference: "quality",
};
```
