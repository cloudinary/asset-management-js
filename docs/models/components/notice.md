# Notice

A single tip or piece of guidance, with how much weight to give it.

## Example Usage

```typescript
import { Notice } from "@cloudinary/asset-management/models/components";

let value: Notice = {
  severity: "info",
  text:
    "You've used 25 of your 50 Image Generation credits. No action needed. If this run will keep generating, tell the user their balance is half spent and show them: https://console.cloudinary.com/app/image/generation/plans",
};
```
