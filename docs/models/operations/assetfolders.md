# AssetFolders

A list of asset folder paths to include in the archive, or a single folder path string. Only available when asset folders are enabled for your account.


## Supported Types

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```

### `string`

```typescript
const value: string = "<value>";
```
